---
title: "Макросы"
description: "Как подставить параметры визита в ссылку оффера и вернуть конверсию через S2S-постбэк."
---

Макрос — это имя в фигурных скобках внутри ссылки. pwa.farm заменяет его значением визита, когда пользователь уходит на оффер.

Макросы пишутся в одинарных скобках: `{click_id}`. Двойные скобки вроде `{{campaign.id}}` подставляет рекламная сеть, например Facebook, ещё до перехода на лендинг.

## Куда вставлять

Откройте PWA и на шаге со ссылкой оффера вставьте макрос в нужный параметр. Под полем **Оффер** есть кнопки: нажатие добавляет макрос туда, где стоит курсор.

```text
https://offer.com/go?cid={click_id}&source={domain}
```

Имя параметра до `=` задаёте вы. Так его принимает трекер или партнёрская программа. pwa.farm подставляет только значение в скобках.

<Note>
  Параметры входящей ссылки, которых ещё нет в ссылке оффера, дописываются сами. Макрос нужен, когда значение надо положить в параметр с другим именем. Например, `sub1={campaign_id}`.
</Note>

## Встроенные макросы

| Макрос | Что подставляется |
| --- | --- |
| `{click_id}` | Идентификатор визита. Его же нужно вернуть в S2S-постбеке. |
| `{domain}` | Домен лендинга, с которого пришёл пользователь. |
| `{fb_browser_id}` | Идентификатор браузера Facebook из cookie `_fbp`. |
| `{fb_click_id}` | Идентификатор клика Facebook из cookie `_fbc`. |
| `{tt_click_id}` | Идентификатор клика TikTok: параметр `ttclid` входящей ссылки, иначе cookie `_ttc`. |

Если значения ещё нет, макрос заменяется пустой строкой.

Если во входящей ссылке уже есть `click_id` или `subid`, при серверном переходе на оффер `{click_id}` получает это значение.

Пример:

```text
https://offer.com/go?cid={click_id}&host={domain}&fbp={fb_browser_id}&fbc={fb_click_id}&ttclid={tt_click_id}
```

## Параметры входящей ссылки

Любое другое имя в скобках берётся из query-параметра лендинга. Регистр не важен: `{Campaign_ID}` и `{campaign_id}` — один и тот же параметр.

Имена из таблицы выше так не подставляются. Для них всегда используется встроенное значение.

Если параметра во входящей ссылке нет, макрос остаётся в ссылке как есть.

В объявлении Facebook можно передать свои метки двойными скобками. На лендинг они придут уже с реальными значениями, а в оффер их можно разложить по сабам:

```text
https://your-domain.com/?campaign_id={{campaign.id}}&adset_id={{adset.id}}&buyer=b1
```

```text
https://offer.com/go?sub1={campaign_id}&sub2={adset_id}&sub3={buyer}&cid={click_id}
```

В партнёрку уйдёт, например, `sub1=6604771447991`, `sub3=b1` и `cid` с идентификатором визита.

У Keitaro параметры по умолчанию называются `sub_id_1` … `sub_id_30`. У Binom имена токенов задаются в источнике. Название до `=` должно совпадать с тем, что принимает трекер. В скобках остаётся имя параметра лендинга или встроенный макрос.

## S2S-постбэки

Постбэк возвращает в pwa.farm конверсию по тому же `{click_id}`, который ушёл в оффер. Шаблоны копируются в карточке **S2S Постбэки** на шаге оффера.

Регистрация:

```text
https://api.pwa-farm.tech/knocks/?click_id={click_id}&event=registration&fb_pixel_id={fb_pixel_id}&tt_pixel_id={tt_pixel_id}
```

Депозит:

```text
https://api.pwa-farm.tech/knocks/?click_id={click_id}&event=deposit&profit={profit}&currency=usd&fb_pixel_id={fb_pixel_id}&tt_pixel_id={tt_pixel_id}
```

В этих ссылках скобки заменяет уже трекер или партнёрка, не pwa.farm. `{click_id}` должен стать тем идентификатором, который вы сохранили из ссылки оффера.

| Параметр | Обязателен | Что передать |
| --- | --- | --- |
| `click_id` | да | Идентификатор визита из `{click_id}` |
| `event` | да | `registration`, `deposit`, `install` или `open` |
| `profit` | для депозита | Сумма депозита |
| `currency` | нет | Валюта суммы, в шаблоне депозита это `usd` |
| `fb_pixel_id` | нет | ID пикселя Facebook. Если не передан, берётся пиксель визита |
| `tt_pixel_id` | нет | ID пикселя TikTok. Если не передан, берётся пиксель визита |

Без `click_id` или `event` постбэк не примется.

Пиксель визита pwa.farm запоминает по параметрам `fpx` и `tpx` входящей ссылки. Как добавить их в ссылку на PWA, описано в разделе [Трекинг](/pwa.farm%20documentation/Трекинг).
