Раздел **«Трекинг»** показывает рекламные пиксели Facebook и TikTok, подключённые к приложению. Баеру здесь нужно найти пиксель для своей рекламной платформы и добавить его **URL-параметр** в ссылку, по которой пользователь переходит на PWA.

<Warning>
Перед запуском трафика добавьте URL-параметр нужного пикселя в ссылку партнёрской сети или в ссылку Keitaro. Без параметра приложение не получит указание, какой пиксель использовать для посетителя.
</Warning>

## Как найти параметр пикселя

1. Откройте **«Трекинг»** в меню приложения.
2. Найдите пиксель для нужной рекламной платформы. Можно воспользоваться поиском по названию, ID или токену и фильтром **Facebook** или **TikTok**.
3. В карточке нужного пикселя найдите поле **URL-ПАРАМЕТР**. На скриншоте ниже стрелка указывает на параметр Facebook.
4. Нажмите значок копирования рядом с параметром, чтобы скопировать его целиком.

<Frame>
  ![Поле URL-параметра пикселя Facebook, отмеченное стрелкой](/images/tracking-url-param.jpg "Скопируйте URL-параметр рядом с нужным пикселем")
</Frame>

Выбирайте параметр именно того пикселя и платформы, с которых идёт реклама. Например, для Facebook используйте параметр Facebook, а для TikTok — параметр TikTok. Не копируйте значение из поля **Pixel ID**: для ссылки нужен параметр из поля **URL-ПАРАМЕТР** целиком, вместе с названием до знака `=`.

## Как добавить параметр в ссылку

Вставьте скопированный параметр в URL, который ведёт пользователя на PWA:

- Если в ссылке ещё нет параметров, добавьте `?`, затем URL-параметр:

  `https://example.com/?fpx=ВАШ_PIXEL_ID`

- Если в ссылке уже есть параметры, добавьте `&`, затем URL-параметр:

  `https://example.com/?subid=123&fpx=ВАШ_PIXEL_ID`

В примерах `fpx=ВАШ_PIXEL_ID` — условный параметр Facebook. Используйте значение из карточки своего пикселя без изменений. Для TikTok вставьте его собственный URL-параметр, начинающийся с `tpx=`.

Добавить параметр можно к ссылке, которую вы настраиваете в партнёрской сети, или к итоговой ссылке перехода на PWA в Keitaro. Если Keitaro передаёт пользователя на отдельный URL приложения, убедитесь, что параметр присутствует именно в этом URL и сохраняется при переходе.

### Проверьте ссылку перед запуском

- В ссылке есть параметр нужной рекламной платформы: `fpx=…` для Facebook или `tpx=…` для TikTok.
- Между доменом и первым параметром стоит `?`, а между последующими параметрами — `&`.
- Исходные параметры ссылки, включая `subid` и макросы партнёрской сети, сохранены.
- Параметр скопирован полностью из поля **URL-ПАРАМЕТР**, а не набран вручную по значению Pixel ID.

## Что ещё видно в списке

- **Название и значок платформы** помогают отличить пиксели друг от друга.
- **Pixel ID** — идентификатор пикселя; он может понадобиться для сверки с настройками рекламной платформы.
- **Флажок** позволяет выбрать одну или несколько карточек.
- **Карандаш** открывает редактирование, **корзина** — удаление пикселя. Баеру обычно достаточно скопировать URL-параметр; не редактируйте и не удаляйте пиксели без согласования с владельцем аккаунта.
- **Поиск, фильтр и пагинация** помогают найти нужную карточку, если в списке много пикселей.
