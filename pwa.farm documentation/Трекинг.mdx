Раздел **«Трекинг»** содержит пиксели Facebook и TikTok, подключённые к приложению. 

<Warning>
  Перед запуском трафика добавьте URL-параметр нужного пикселя в ссылку партнёрской сети или в ссылку Keitaro. Без параметра приложение не получит указание, какой пиксель использовать.
</Warning>

## Как найти параметр пикселя

1. Откройте **«Трекинг»** в меню приложения.
2. Найдите пиксель для нужной рекламной платформы. Можно воспользоваться поиском по названию, ID или токену и фильтром **Facebook** или **TikTok**.
3. В карточке нужного пикселя найдите поле **URL-ПАРАМЕТР**. На скриншоте ниже стрелка указывает на параметр Facebook.
4. Нажмите значок копирования рядом с параметром, чтобы скопировать его целиком.

<Frame>
  ![Поле URL-параметра пикселя Facebook, отмеченное стрелкой](/images/tracking-url-param.jpg "Скопируйте URL-параметр рядом с нужным пикселем")
</Frame>

Выбирайте параметр именно того пикселя и платформы, с которых идёт реклама. Например, для Facebook используйте параметр Facebook, а для TikTok — параметр TikTok. Не копируйте значение из поля **Pixel ID**: для ссылки нужен параметр из поля **URL-ПАРАМЕТР** целиком, вместе с названием до знака `=`.

## Как добавить параметр в ссылку

Вставьте скопированный параметр в URL, который ведёт пользователя на PWA:

- Если в ссылке ещё нет параметров, добавьте `?`, затем URL-параметр:

  `https://example.com/?fpx=ВАШ_PIXEL_ID`
- Если в ссылке уже есть параметры, добавьте `&`, затем URL-параметр:

  `https://example.com/?subid=123&fpx=ВАШ_PIXEL_ID`

В примерах `fpx=ВАШ_PIXEL_ID` — условный параметр Facebook. Используйте значение из карточки своего пикселя без изменений. Для TikTok вставьте его собственный URL-параметр, начинающийся с `tpx=`.

Добавить параметр нужно к ссылке, которую вы настраиваете в партнёрской сети, или к итоговой ссылке перехода на PWA в Keitaro. Если Keitaro передаёт пользователя на отдельный URL приложения, убедитесь, что параметр присутствует именно в этом URL и сохраняется при переходе.

### Проверьте ссылку перед запуском

- В ссылке есть параметр нужной рекламной платформы: `fpx=…` для Facebook или `tpx=…` для TikTok.
- Между доменом и первым параметром стоит `?`, а между последующими параметрами — `&`.
- Исходные параметры ссылки, включая `subid` и макросы партнёрской сети, сохранены.
- Параметр скопирован полностью из поля **URL-ПАРАМЕТР**, а не набран вручную по значению Pixel ID.

## Добавление пикселя

1. В разделе **«Трекинг»** нажмите **«Добавить пиксель»**. На скриншоте стрелка указывает на эту кнопку.
   ![Кнопка «Добавить пиксель» в разделе «Трекинг»](/images/tracking-add-button.jpg "Нажмите, чтобы открыть форму подключения пикселя")
2. В форме выберите **Facebook** или **TikTok**.
3. Заполните основные параметры пикселя.
4. Сопоставьте события PWA с событиями рекламной платформы.
5. Нажмите **«Сохранить»**. Проверьте, что пиксель появился в списке.

### Пиксель Facebook

Для Facebook заполните поля в блоке **«Основные параметры пикселя»**:

- **Пользовательское имя пикселя** — понятное название для списка пикселей.
- **Числовой ID из администратора Facebook** — ID из Facebook Business Manager.
- **API token Facebook Pixel** — токен для передачи событий через Facebook Conversion API.

Затем в блоке **«События Facebook»** выберите событие Facebook для каждого события PWA. Например, можно сопоставить открытие страницы с `ViewContent`, установку с `Lead`, регистрацию с `CompleteRegistration`, а депозит с `Purchase`. Выбирайте соответствия, принятые для вашей кампании.

![Форма добавления пикселя Facebook и сопоставление событий](/images/add-pixel-facebook.jpg "Настройки Facebook Pixel")

### Пиксель TikTok

Для TikTok заполните поля в блоке **«Основные параметры пикселя»**:

- **Пользовательское имя пикселя** — понятное название для списка пикселей.
- **TikTok Pixel ID** — ID из TikTok Ads Manager.
- **Access Token** — токен доступа для интеграции с TikTok Business API.

В блоке **«События TikTok»** сопоставьте события PWA с событиями TikTok. Например, открытие страницы можно сопоставить с `ViewContent`, установку — с `Download`, регистрацию — с `CompleteRegistration`, депозит — с `Purchase`. Выбирайте соответствия, принятые для вашей кампании.

![Форма добавления пикселя TikTok и сопоставление событий](/images/add-pixel-tiktok.jpg "Настройки TikTok Pixel")
