Добавьте пиксели Facebook и TikTok, чтобы отслеживать конверсии и улучшать таргетирование объявлений.

## Список пикселей

На странице отображаются подключенные пиксели. В строке каждого пикселя показаны платформа, название, Pixel ID и URL-параметр для передачи идентификатора в ссылке.

### Поиск и фильтрация

Введите в поле поиска название пикселя, его ID или токен. Чтобы отфильтровать список по рекламной платформе, откройте фильтр и выберите **Все**, **Facebook** или **TikTok**. Рядом с выбранным фильтром отображается количество пикселей.

### Выбор пикселей

Отметьте флажок рядом с нужными пикселями. Чтобы выбрать все пиксели в списке, используйте флажок **«Выбрать все»** над карточками.

### Данные и действия

В карточке пикселя отображаются логотип и название платформы, а также:

- **Pixel ID** — идентификатор пикселя. Нажмите значок копирования рядом с ним, чтобы скопировать значение.
- **URL-параметр** — параметр для ссылки с идентификатором пикселя. Нажмите значок копирования рядом с ним, чтобы скопировать значение.

Для изменения настроек нажмите значок карандаша. Чтобы удалить пиксель, нажмите значок корзины.

### Переход между страницами

В нижней части списка можно выбрать количество строк на странице и перейти к предыдущей или следующей странице. Текущая страница и общее количество страниц отображаются рядом с настройкой количества строк.

## Добавление пикселя **Facebook**

Нажмите **«Добавить пиксель»**, чтобы открыть форму подключения. Для Facebook:

1. В блоке **Основные параметры пикселя** выберите тип **Facebook**.
   ![Форма добавления пикселя Facebook](/images/Zrzut-ekranu-2026-09-25-o-13.59.31.png "Форма добавления пикселя Facebook")
2. Заполните поля:
   - **Пользовательское имя пикселя** — название, под которым пиксель будет отображаться в системе.
   - **Числовой ID из администратора Facebook** — идентификатор из Facebook Business Manager.
   - **API Token Facebook Pixel** — токен для передачи событий через Facebook Conversion API.
3. В блоке **События Facebook** сопоставьте события приложения (PWA) с событиями Facebook.
   ![Настройка событий Facebook](/images/Zrzut-ekranu-2026-09-25-o-13.58.26.png "Настройка событий Facebook")
4. Нажмите **«Сохранить»**. После сохранения пиксель появится в списке и начнет передавать выбранные события в Facebook.

## Добавление пикселя TikTok

Нажмите **«Добавить пиксель»**, чтобы открыть форму подключения. Для TikTok:

1. В блоке **Основные параметры пикселя** выберите тип **TikTok**.
   ![Форма добавления пикселя TikTok](/images/Zrzut-ekranu-2026-09-25-o-13.59.31-1.png "Форма добавления пикселя TikTok")
2. Заполните обязательные поля:
   - **Пользовательское имя пикселя** — название, под которым пиксель будет отображаться в системе.
   - **TikTok Pixel ID** — идентификатор из TikTok Ads Manager.
   - **Access Token** — токен доступа для интеграции с TikTok Business API.
3. В блоке **События TikTok** сопоставьте события приложения (PWA) с событиями TikTok.
   ![Настройка событий TikTok](/images/Zrzut-ekranu-2026-09-25-o-14.00.53.png "Настройка событий TikTok")
4. Нажмите **«Сохранить»**. После сохранения пиксель появится в списке и начнет передавать настроенные события в TikTok.
